# TaskTracker 後端

開發請先閱讀本目錄 [AGENTS.md](AGENTS.md) 及根目錄 [AGENTS.md](../AGENTS.md), 安裝與操作見[根 README](../README.md)

Laravel 只提供 JSON API, 前端 Vue＋Vuetify 位於 `../frontend`, 不使用 Inertia。不得把憑證、資料庫或編譯產物加入 Git

後端開發與測試設計亦須讀 [ECC laravel-patterns](../skills/vendor/laravel-patterns/SKILL.md) 及 [Laravel Architecture](../skills/laravel-architecture/SKILL.md)，按需選讀其references。架構慣例衝突以ECC為準；產品契約與資料安全限制沿用AGENTS。舊後端skill已移除，本輪重構暫緩。
