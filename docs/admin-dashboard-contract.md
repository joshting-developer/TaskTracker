# 管理後台契約

TT-364, 後端與管理介面已完成隔離驗證, 正式配置與整批部署待後續驗收

## 管理身分

單一獨立管理帳號由 `TASKTRACKER_ADMIN_USERNAME` 與 `TASKTRACKER_ADMIN_PASSWORD_HASH` 提供, 密碼只保存Laravel支援的雜湊。未配置就拒絕登入, 不提供預設管理密碼、不建立一般User、不將Owner或PAT升成平台管理者

管理資格使用伺服器Session的獨立欄位, 與一般User guard分開。沿用既有安全Cookie、來源限制、CSRF及Session blocking, 不是新增另一套Cookie協定。成功登入與登出輪替Session ID及CSRF；登出只移除管理資格, 一般產品登入保留。一般產品登出會銷毀整個Session, 管理資格也隨之結束

資格固定30分鐘到期, 不因讀統計自動延長。每次管理請求重驗資格與配置HMAC, 改管理名稱／密碼雜湊後舊資格立即失效。多台服務須使用相同配置, 秘密更新須完成所有機器更新才能視為全站撤銷

登入每來源每分鐘5次, 統計及列表各30次。所有管理JSON禁止快取, 不讀任意客戶端提供的Owner、Scope或管理欄位作資格

## 介面分工

| HTTP | 路徑 | 資料 |
| --- | --- | --- |
| POST | /api/admin/session | username、password, 驗證後建立管理Session |
| GET | /api/admin/session | 管理名稱, 不回傳資格指紋或密碼雜湊 |
| DELETE | /api/admin/session | 清除管理資格 |
| GET | /api/admin/statistics?days=7 | 固定7或30日的全站彙總及趨勢 |
| GET | /api/admin/workspaces?before=… | 最新工作區必要識別, 每頁20筆 |

成功沿用 `{ok,data}` Resource, 未登入401, 不支援的期間／游標422。不是公開PAT API, 不放進對外OpenAPI。使用現有 `/api/csrf-cookie` 取得CSRF, 密碼不放URL

## 統計定義

- 帳號／工作區總數：目前users、workspaces資料表的列數, 包含沒有有效工作區的帳號, 不代表付費或活躍
- 活躍帳號／工作區：固定期間內, 有成功HTTP寫入紀錄且同時帶可信帳號、工作區識別的去重數。排除驗證、管理後台及GET／HEAD／OPTIONS。保留的歷史身分可能已刪除, 因此不能拿活躍數除以目前帳號數作百分比。不是登入數、瀏覽人數、留存率或出勤
- 趨勢：UTC日曆日, 包含今天, 最近7或30日。SQL先依UTC起迄篩選再聚合, 最多30列, Service補零
- 建卡／留言／填報工時：成功單筆入口的請求次數, 包含Web及公開單筆建卡／留言。工時目前只計Web填報。不是現存實體數、時數, 不包含批次upsert、離線匯入；同一requestId重送成功也可能再次計入
- 紀錄自HTTP操作紀錄功能啟用後才有, 保存90日, 不回填歷史。紀錄失敗只記受控log, 因此不能當作會計稽核

## 資料存取審查

1. 統計只取整數總計、日期與次數, 列表只取工作區公開ID、名稱、建立時間。平台管理者取得全站必要彙總, 不取得一般Workspace操作資格
2. 統計最多30列；工作區固定20筆, id倒序游標多取一筆判斷下一頁, 無深OFFSET
3. 期間、成功狀態、身分與路由排除在SQL執行, 不載整包工作區或活動到PHP篩選
4. 一次統計4個SQL：期間去重、每日聚合、帳號COUNT、工作區COUNT；列表1個SQL, 沒有逐列關聯查詢
5. 不選取卡片、留言、紙條、附件、密碼、Email、Token或紀錄payload
6. 前端只在載入／切換期間／手動重整觸發, 不輪詢。總計COUNT及去重成本仍隨全站／期間資料增加, 有界回應不等於固定耗時；先沿用occurred_at索引, 未量測前不加cache或索引
7. 測試同時放入期間外、失敗、驗證、無身分及其他工作區資料, 驗回應與實際SQL投影、範圍、排序及上限
8. 正式MySQL拓樸與流量尚未量測, 隔離SQLite／MySQL通過不當作正式p95驗收。正式配置與部署待後續階段

## 後端階段實測

隔離SQLite＋MySQL及Container／分層／PHPDoc／既有帳號契約通過。MySQL加入1000筆期間外歷史後, 兩個活動聚合均使用既有http_operation_logs_retention的range掃描, 估計讀取少於100列；回應只包含期間內1筆成功請求。這是隔離引擎範圍及索引證據, 不是正式負載延遲

真實隔離HTTP確認缺CSRF回419、跨來源403、未登入統計／工作區401。前端階段另以真實Chrome驗證成功登入、分頁、語言切換及登出, 不以PHPUnit取代

## 管理入口

獨立入口為`/admin/`, 登入後讀取統計與工作區列表, 不載入一般工作空間。統計可選7／30日, 每日明細按需展開；工作區先顯示5筆, 查看全部後每頁20筆, 前後頁不累積DOM

頁面與HTTP回應禁止索引, 登出卸載統計。兩種語言沿用既有偏好元件, 不新增輪詢。管理者帳密必須由部署Secrets配置, 缺少配置時不能登入, 不提供一般Owner／PAT替代路徑

隔離驗收fixture與router在bootstrap前檢查testing、專用旗標、資料庫名稱與帳號, 不放入正式映像。固定日期保留即時秒數, 讓限流到期正常運作
