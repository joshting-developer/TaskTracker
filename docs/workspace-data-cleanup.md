## 操作保護

tools/workspace-data-cleanup.php是一次性CLI維護工具, 不加入產品HTTP介面。預設完整回滾, 明確帶--apply才提交, 兩種模式都會鎖定與核對目前資料

- manifest與連線檔必須是0600一般檔案, 不接受symlink
- 指定資料庫、工作區ID／公開ID／名稱、全部工作區清單與保留／移除帳號清單必須完全吻合, 多出帳號或工作區就停下來重新盤點
- 提交前需存在完整備份且SHA256與manifest一致
- 外鍵全程開啟, 子表先刪；原卡片、留言、工時、紙條、專案、看板、附件的保留數量不可減少
- 舊AI與Claude的Project ACL只有相同grant才能合併, 衝突直接回滾, 不自行升權
- 私人紙條參與者合併要處理唯一鍵, 原指派與作者轉到明確目標；其他不要的帳號若仍有保留資料參照就拒絕清理
- 不改使用者寫下的長篇文字, 只轉移結構化身分欄位及JSON完整值。舊帳號receipt與PAT刪除而不轉交, 保留帳號的重播規則不改
- 歷史records僅允許已確認屬於刪除目標的舊示範工作區, 發現未知scope就回滾

此工具不自行停止服務、備份或提供授權。執行者仍須讀目前卡片及使用者核准, 先備份、隔離還原演練, 再暫停全部正式寫入與自動喚醒；不能拿備份雜湊當作刪除授權
