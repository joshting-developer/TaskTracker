# TT-331 紙條頁改版

紙條從首頁移到 `#/notes`, 側邊欄提供連結, 支援右鍵開分頁。首頁先留空, 不新增摘要或小工具

四個分頁為建立、待處理、我交辦的、我經手的。列表只呈現標題、來源與時間；完成狀態必要時附在來源列, 不在列表展開原稿或歷程。更多按鈕開右側抽屜, 手機為滿寬抽屜

目前承辦人可在抽屜下方寫回覆並選要傳給誰。傳遞是主要動作, 完成獨立放在標題列；兩者都附帶回覆。前經手者看歷程, 沒有傳遞／完成操作。編輯、重新開啟與取消仍依原能力顯示

## 資料存取與相容

- Session與PAT沿用同一Controller → Service → Repository查詢鏈, 沒新增角色名稱放行
- mine／open為待處理；sent改為本人建立（包含交給自己）, involved維持本人參與範圍；state=all合併狀態, 都在SQL先限定Workspace／參與者後篩選與分頁
- UI每頁20筆, API上限100；排序仍依updated_at及穩定ID, 列表Resource不含原稿、note、留言、歷史或交接
- 列表不再取未使用的counts與Project候選。點更多才讀詳細、留言及交接各20筆；轉卡資格候選最多1筆, 在詳細讀取時才查。背景版本變動只重讀目前抽屜, 不替所有曾點過的紙條暖快取
- 紙條路由納入scoped bootstrap, 不走整包Workspace；首頁不掛個人列表查詢, 全域通知仍只做既有輕量版本／未讀同步
- `/todos`、資料表及CLI `todo-*`命令保留；OpenAPI 0.20.0說明state=all與sent範圍。外部comment／return接口保留, 本次只移除網頁的單獨回覆／退回上一手
- revision／requestId、草稿、撤權與參與者隱私維持；列表成長不是固定延遲, 本輪不宣稱正式p95或遠端拓樸效能
