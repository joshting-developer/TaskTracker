# 介面文案盤點與精簡

日期：2026-11-06（Asia/Taipei）

使用者要求移除情緒性文案及過多功能介紹。操作手冊之後另行指示，本輪只清理介面，不製作手冊。

## 本輪調整

| 範圍 | 移除或精簡 |
| --- | --- |
| 全域 | 頁尾鼓勵語、本機試用標籤、專案入口英文標語與導讀；頁尾版本保持底部靠右 |
| 登入／註冊 | 形象標語、產品介紹、Google登入比較及加入團隊教學；保留品牌、登入／註冊切換與邀請目標 |
| 首頁待辦 | 鼓勵副標、常駐隱私介紹；空狀態改直接描述，保留交辦來源與實際狀態 |
| 專案列表／表單 | 空白頁勵志標題、示範專案教學、新專案卡口號、建立表單導讀；載入結果改成「已載入示範專案」 |
| 任務表單／留言 | 建立及編輯前言、留言邀請語、新增後可在哪裡查看的提示；placeholder改用直接欄位名稱 |
| 看板列表／編輯／看板 | Default及Epic收錄教學、拖曳／雙擊介紹、沒有資料時的操作教學；保留收錄數、卡片數、同步狀態與控制項 |
| 工時月曆／填報 | 情緒性頁名、點日期教學、時區副標、工時填報介紹／換算教學與報表口徑；保留日期、實際工時、月總計、欄位及驗證錯誤 |
| 工時分析 | 三種分析介紹、最多366天／時區提示、有效紀錄／Epic去重／績效等長段說明；三個入口縮為標題與箭頭 |
| 成員／工作空間設定 | 權限模型導讀、角色介紹、改名影響、資格移除歷史、邀請使用教學；保留身份選單、成員資料、設定版本與儲存結果 |
| 工作區切換／邀請 | 切換器教學、接受後專案授權介紹；保留目標名稱、受邀Email、Email不符及失效錯誤 |
| 狀態設定 | 宣傳式標題、分類與完成率教學、頁尾常駐使用規則；保留欄位、使用中不可移除原因與後端驗證 |
| 通知／SMTP | 產生通知的教學、空白頁引導、重複英文預覽標籤；保留「尚未寄送」、設定狀態、收件人與通知內容 |
| Markdown編輯器 | 常駐Markdown／Enter教學；保留工具列、預覽、字數、錯誤及無障礙訊息 |

## 保留與界線

- 使用者輸入的專案介紹、任務描述、留言、工時說明與通知內容是資料，本輪不刪改。
- 保留必要標題、欄位、操作、數值、日期、查詢範圍、權限／唯讀狀態、載入／空資料與操作結果。
- 保留失敗原因、版本衝突、未保存確認與會改變授權／資料的確認。不把文案精簡擴張成放寬規則。
- 日期上限仍是366日，工作日仍採Asia/Taipei，Epic工時去重與作者限制均不變；輸入無效時仍回傳明確錯誤。
- 少數短輸入限制（密碼長度、代碼格式）留在欄位旁；長篇規則及常駐教學不預先補回。
- 系統現在以簡短事實描述空狀態，例如「尚無專案」「尚無任務」「尚無留言」。

## 驗證

前端production build及完整browser-check通過；編譯版工時分析測試驗證日期上限錯誤、篩選、加總與撤權仍有效，並檢視桌面／平板／手機。既有首頁測試改用新的事實型標題，不另建立低風險文案專用測試套件。測試僅使用獨立Laravel API與假資料，未修改業務資料。
