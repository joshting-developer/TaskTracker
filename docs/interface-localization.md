# 介面語系

TT-308目前提供繁體中文（zh-TW）與英文（en）, 登入流程與工作介面共用同一份語系狀態

## 偏好與切換

- 公開頁及登入頁從上方導覽選擇, 登入後從右上語言選單選擇；帳號選單不再重複放入口
- 明確選擇記在這個瀏覽器共用的tasktracker:locale, 公開頁／登入／App沿用；沒有偏好時依瀏覽器支援的語言, 其他語言回繁中
- 舊的各帳號偏好資料保留作相容fallback, 新的瀏覽器明確選擇優先, 切換帳號不自動重設語言；不影響帳號及資料隔離
- 切換不重整頁面、不重新掛載編輯器、不請求Workspace資料, 既有草稿、權限與租戶狀態保留
- 不跨裝置同步語言偏好, 清除瀏覽器資料後回到瀏覽器語言

## 翻譯範圍

系統標題、按鈕、欄位、驗證、確認訊息及日期／數字／工時顯示由前端翻譯目錄處理, Vuetify內建介面同步切換

卡片、紙條、留言、成員名稱、專案／看板介紹與自訂狀態名稱都是使用者資料, 維持原文。既有伺服器產生並儲存的通知／郵件內容維持原文, 不透過改介面語言重寫歷史

TT-365補上五個英文公開介紹頁的同網址呈現, 未提供英文開發者文件或英文郵件範本, 沒有新增英文公開網址或hreflang。不將任何內容傳給外部翻譯服務

## API與資料邊界

- 後端錯誤code、原message及HTTP狀態不改契約, 前端保留originalMessage並顯示可定位的英文訊息；未知錯誤顯示一般失敗訊息, 不把原始中文當英文介面
- 語言不影響permission、scope、角色ID、狀態ID、requestId、revision或排序
- 日期時間顯示依目前語系, 工作日仍使用Asia/Taipei與YYYY-MM-DD機器值
- 沒有新增語系API、SQL、輪詢或整包Workspace載入。翻譯目錄隨前端build發佈, 沒有額外網路請求

## 維護

`frontend/src/i18n/zh-TW.json`與`en.json`的key與參數需一致, `t()`只用在系統文案, 不套用到使用者標題或描述。參數以Vue文字插值呈現, 不改用v-html

新增系統文字時同步補兩份目錄, 執行`node frontend/tools/i18n-check.js`；真實流程使用Codex／Claude專屬隔離環境執行`npm run test:i18n`。完整回歸與視覺基準依專案測試Skill

公開頁的翻譯、安全與SEO邊界見[公開頁語系契約](public-language-contract.md)
