# 任務計畫日期

TT-368, Season 0

- `startDate`：計畫開始日；`endDate`：計畫結束日；`dueDate`：獨立的最晚交付日
- 三種類型 Epic／Task／Bug 共用, 計畫日期可不填或只填一端, 不自動推算或搬移到期日
- 都有值時結束日不可早於開始日, 同日合法；允許 1000-01-01 至 9999-12-31 的真實日期
- 資料庫使用可空 DATE, API 使用 YYYY-MM-DD, 不轉 UTC 或依瀏覽器時區移動日期
- Web 編輯的任務屬性與完整頁顯示兩個日期, 列表不增加未使用的計畫日期資料
- Web／PAT 共用驗證與歷史；PATCH 省略保持原值, 空字串或 null 清除計畫日期, revision／requestId 與既有權限相同
- 只新增可空欄位, 舊卡片保持未設定, 不從 dueDate 推算；不新增索引或排程視圖

公開 API 建卡或更新可帶以下欄位, 仍須提供對應的 requestId 與更新用 expectedRevision

```json
{
  "startDate": "2028-02-29",
  "endDate": "2028-03-02",
  "dueDate": "2028-03-10"
}
```

詳細 API 回傳兩個計畫日期；列表、看板摘要與候選不增加這兩欄。新的排程列表若需要日期, 另依資料存取審查定義有界契約
