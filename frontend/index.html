從一件小事到完成

TaskTracker 的日常大概是這樣走的。

  1. 1

    先記下來

    首頁的個人待辦隨手就能記，支援 Markdown。只有自己看得到，也可以交辦給同事、讓對方退回。

    問設計那邊登入頁的錯誤文案
    重設密碼信的連結要幾小時失效？
    整理上週會議紀錄
  2. 2

    需要排進專案時，轉成任務

    一件待辦變成正式工作時，直接轉成專案任務，原本寫的內容會一起帶過去，之後也看得到它從哪裡來。

    重設密碼信的連結要幾小時失效？
    轉成任務
    TT-16・Task重設密碼信的連結要幾小時失效？
  3. 3

    在看板上推進

    拖曳卡片就能換狀態。每個專案可以有好幾個看板，收錄一個 Epic 時，它底下的卡片會自動一起出現。

    待規劃

    TT-16・Task重設密碼信的連結要幾小時失效？

    進行中

    TT-10・Task登入頁與重設密碼
  4. 4

    記下花了多少時間

    在任務上填每天的工時，專案月曆、每個成員的投入和趨勢都看得到，不用另外開一份工時表。

    11/12（三）TT-10 登入頁與重設密碼1.0 h
    11/13（四）TT-10 登入頁與重設密碼0.5 h
    本週王小明・會員功能6.5 h

其他也做得到

專案權限
依專案成員的角色決定可讀、可寫或可管理，私人專案的任務不會出現在其他人的畫面。
任務列表與篩選
依狀態、類型、負責人、到期日篩選與排序，任務頁可以留言、查看異動紀錄。
工時分析
看專案月曆、成員投入與趨勢，也能點進去看每張卡花了多少時間。
API 與整合
建立個人 API Token，透過公開 REST API 查詢、建立與更新任務，附 OpenAPI 文件。

三步開始

  1. 建立工作空間用 Email 註冊，替你的團隊空間取個名字。
  2. 建立專案和看板設定專案代碼、狀態，以及要追蹤的 Epic。
  3. 邀請成員產生邀請連結給同事，依專案指派角色後就能一起用。
