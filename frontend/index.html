從找不到順手的工具開始

換過工作, Josh 還是找不到用得順手的專案管理工具。於是他決定自己做, 這就是 Pavenro 的起點

Pavenro 把任務、團隊交辦與工時紀錄放在同一個工作空間。正式工作用任務追蹤, 小事先留在紙條裡, 需要時再轉成任務

常見問題

紙條與任務有什麼不同？

紙條用來速記與交辦, 可以回覆、轉交、完成或退回。需要排進專案追蹤時, 再從紙條轉成任務, 保留內容與來源

可以在多個工作空間工作嗎？

同一個帳號可以切換有資格存取的工作空間, 分別處理各空間的專案與紙條。切換不會合併看板或工時報表

工時會自動記錄嗎？

工時由本人填報在任務上, 再依專案、成員或日期查看。填報紀錄不是自動計時或產能評分, 也只能修改自己的有效紀錄

能串接自己的程式或 AI 工具嗎？

可以使用個人 API Token 與公開 REST API 依契約串接。Token 仍受本人當下權限與指定工作空間限制, 不是每個畫面操作都有公開 API

如何開始使用？

註冊並驗證信箱後, 可以建立工作空間與專案；如果收到邀請, 先確認邀請再加入。已有帳號可從頁面上方登入
