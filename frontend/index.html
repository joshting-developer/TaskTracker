目前提供的功能

  • 專案與看板

    每個專案有自己的狀態設定與多個看板；收錄 Epic 會自動帶入所屬卡片，可拖曳變更狀態。

  • 任務列表與篩選

    依狀態、類型、負責人、到期日篩選與排序，任務詳細頁可留言並查看異動紀錄。

  • 個人待辦與交辦

    首頁的個人待辦支援 Markdown，可交辦給同事、退回，也能直接轉成專案任務。

  • 工時填報與分析

    依工作日記錄每人每日工時，查看專案月曆、成員投入與趨勢。

  • 專案權限

    以專案成員角色決定可讀、可寫或可管理；私人專案的任務不會出現在其他人的畫面。

  • API 與整合

    可建立個人 API Token，透過公開 REST API 查詢、建立與更新任務，並有 OpenAPI 文件。

開始使用

  1. 建立工作空間：用 Email 註冊並命名你的團隊空間。
  2. 建立專案與看板：設定專案代碼、狀態與要追蹤的 Epic。
  3. 邀請成員：產生邀請連結給同事，依專案指派角色後開始協作。
