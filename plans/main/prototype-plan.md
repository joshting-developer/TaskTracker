# 第一版可操作原型

日期：2026-10-05（Asia/Taipei）

## 使用者指示

> 先做一版試試看吧 然後其實我看不太懂甘特圖

## 範圍與選擇

- 建立 Vue＋Vite 前端、本機 Node API＋SQLite 持久化, 使用清單與狀態看板
- 可建立專案、新增／修改任務、搜尋與篩選、查看詳細內容、追加留言及查看異動
- 看板拖曳更新狀態, 同時保留選單操作供手機與鍵盤使用
- 固定優先級、類型、狀態, 不做甘特圖、Sprint、自訂欄位引擎或通知
- 本機先作單人原型, 不虛構團隊帳號或多人權限；伺服器只綁 loopback
- 使用者後續指示先不產生 GAS／`.gs`, 等本機版本確認後再處理, 本次只保留 API 與 domain 分層
- 新專案保持空資料, 另提供明確標示的手動載入示範資料操作, 便於試用

UI 採簡潔的深色側欄與明亮任務工作區, 不依賴額外 UI 框架。這是本次原型的可逆選擇, 不視為後續視覺規格已定案

## 既有狀態

main 尚無 commit, 前次交付的 6 份文件為未追蹤檔案, 保留所有文件；參考專案唯讀

## 步驟與驗證

1. 建立依賴、共用 domain、API 與 SQLite repository → 隔離資料庫測試保存、版本衝突、重試與留言
2. 建立 Vue 工作區、表單與看板 → build, 檢查空／錯誤／保存狀態
3. 保留前端 API 與 domain 分層 → 本次不產生 `.gs`, 不做雲端編譯或部署
4. 啟動本機前後端與瀏覽器驗證 → 專案／任務 CRUD、搜尋、看板、留言、重新整理、手機尺寸
5. 更新 README、AGENTS 與驗證紀錄 → 提供可開啟的本機網址, 記錄 GAS 產檔延後

## 待確認與限制

- 正式 Apps Script／試算表尚未提供, 本次不初始化雲端或部署
- 單人原型的負責人是文字欄位, 尚未與帳號綁定, 不聲稱已支援團隊 ACL
- 原型的測試資料可以手動匯入, 不把示範內容當正式需求
