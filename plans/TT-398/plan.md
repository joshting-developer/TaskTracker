# 通知日期與工作區時區

- 預估 60 分鐘, 先比對正式 UTC 原始值、MySQL 時區與前端顯示, 不先假定 VM 時區是根因
- 持久時間繼續以 UTC 儲存及 ISO 8601 Z 回傳, 工作區提供 IANA 顯示時區, 預設 UTC
- 保留既有工時工作日 Asia/Taipei 契約, 不在顯示時區設定時重寫歷史資料或工時歸屬
- 共用設定入口、版本／requestId 與 permission 保留, SQL 僅多讀目前工作區的一個欄位, 不擴大列表
- SQLite 與隔離 MySQL 功能測試、跨日時間及工作區切換、真實瀏覽器與視覺比較後提交, 再回 TT-396 發布
